# 초보운전탈출 (구 옆자리 쌤): 조수석 운전연수 선생님 앱

> 현대자동차그룹 차량용 앱 개발 공모전 출품 콘셉트 · Pleos Connect · 2026-11-08 기준

**한 줄 콘셉트**
차량 센서와 내비 안내를 실시간으로 읽고, **"지금 이 순간 무엇을 해야 하는지"** 음성으로 알려주는 초보운전자용 동승 연수 강사 앱.

**포지셔닝**
"주차를 대신 해주는 앱"이 아니라 **"도로 위 상황 판단과 조작을 가르쳐주는 앱"**.

---

## 1. 문제와 타깃

### 타깃
- 신규 면허 취득자
- 장롱면허 복귀자
- 새 차를 샀거나 처음 타는 차를 운전하는 사람 (렌터카, 카셰어링 포함)

### 문제
- 연수 강사는 비싸고, 함께하는 시간도 몇 시간뿐이다. 혼자 운전을 시작하는 순간부터 막막해진다.
- 회전교차로, 고속도로 합류, 비보호좌회전, 어린이보호구역처럼 **상황 판단이 필요한 구간**에서 실수가 많다.
- 깜빡이 누락, 급제동, 과속 같은 습관은 누가 옆에서 짚어주지 않으면 고쳐지지 않는다.
- 유튜브나 폰 앱은 운전 중에 쓸 수 없고, 내가 실제로 어떻게 조작하고 있는지도 알지 못한다.

## 2. 왜 폰이 아니라 차량 앱인가
| 구분 | 폰 앱 | 초보운전탈출 (차량 앱) |
|---|---|---|
| 조작 인식 | 불가 (GPS, 가속도 추정만 가능) | 조향각, 깜빡이, 브레이크, 기어, 속도를 **직접 판독** |
| 상황 예고 | 별도 내비와 분리되어 있음 | 차량 내비 안내 이벤트와 실시간 연동 |
| 주행 중 사용 | 화면 조작이 위험함 | 주행 중에는 음성만, 정차 중에는 화면을 쓰도록 주행 규제(CarUxRestrictions)에 맞춰 설계 |

## 3. 핵심 기능

### ① 상황 예고 코칭 (메인 기능, 주행 중 음성 전용)
내비 안내 이벤트를 받아서 상황이 **오기 전에** 강사처럼 미리 말해준다.

| 상황 | 음성 코칭 예시 |
|---|---|
| 회전교차로 | "300m 앞 회전교차로예요. 이미 돌고 있는 차가 우선이니 왼쪽을 보고 천천히 진입하세요." |
| 고속도로 합류 | "곧 합류해요. 깜빡이 켜고 가속 차로에서 속도를 맞추세요." |
| 어린이보호구역 | "어린이보호구역이에요. 30km/h 이하, 횡단보도 앞에서는 일단 멈춤!" |
| 비보호좌회전 | "비보호좌회전이에요. 맞은편 직진 차가 지나간 뒤에 도세요." |
| 단속 카메라·제한속도 | "제한속도 60이에요. 지금 68이니 조금 줄일게요." |

- 사용 API 후보는 NaviHelper의 `onTBTInfo`, `onCautionPointInfo`, `onCameraAlert`, `onCurrentRoadSpeedLimit`다. 각 이벤트의 필드 구성은 확인이 필요하다.
- 이벤트로 알 수 없는 상황은 자체 상황 DB(지도 데이터의 회전교차로 위치 등)와 FusedLocation 위치로 보완한다.

### ② 실시간 조작 피드백
차량 센서로 실제 조작을 확인하고, 그 즉시 짧게 교정하거나 칭찬한다.

- **깜빡이 누락**: 조향각이 크게 바뀌었는데 TurnSignal이 꺼져 있으면 "차선 바꿀 땐 깜빡이 먼저!"
- **급제동**: 브레이크 페달 값이 급하게 오르면 "조금 더 일찍, 부드럽게 밟아볼까요?"
- **과속**: 차량 속도가 도로 제한속도를 넘으면 안내한다.
- **칭찬**: "방금 합류 완벽했어요." 같은 말로 자신감을 높인다.
- **개입 빈도 조절**: 왕초보 단계에서는 자주, 숙련될수록 줄여서 잔소리 피로를 막는다.

### ③ ~~내 차 익히기 튜토리얼 (정차 중)~~ — 제거(#35)
- 에뮬레이터·서드파티 권한으로 확인할 수 있는 조작이 깜빡이·브레이크뿐이라 효용이 낮아 뺐다. 정차 중 학습은 차량 기능 도움말(#29)이 맡는다.

### ④ 주차 절차 코치 (보조 기능)
카메라 없이도 실제 연수 강사 방식대로 가르친다. 판단하는 눈은 운전자이고, 앱은 다음 세 가지를 맡는다.

1. **절차 안내**: 후진, 평행, 전면 주차 유형별로 단계와 **기준점**을 음성으로 안내한다.
   - 예: "뒷바퀴가 주차선 끝을 지나는 순간 핸들을 끝까지 꺾으세요."
2. **조작 확인**: 조향각을 실시간으로 읽어서 정확한 조작인지 확인한다.
   - "아직 끝까지 안 꺾었어요." / "바퀴가 덜 풀렸어요, 반 바퀴 더."
   - 브레이크 값을 보고 "살짝 밟고 천천히요."라고 속도도 코칭한다.
3. **타이밍 신호**: 운전자가 기준점에 오면 차를 멈춘다. 앱은 "움직인 뒤 정지"를 감지해 다음 단계로 넘어간다.
   - 구현(#37): R에서는 시스템 후방카메라 화면이 앱을 덮어서(실측) 화면 버튼에 기댈 수 없다. "지났어" 음성은 STT가 나오면 검토.

- 기어가 R로 바뀌면 자동으로 시작한다(구현 #37: D/N → R일 때만. P → R은 주차칸에서 빼는 경우라 제외). 후진·평행 주차 구현, 전면 주차는 R을 쓰지 않아 제외. 화면에는 시스템 후방카메라 영상이 그대로 나오고, 앱은 그 위에 음성으로 코칭한다.
- 정차 중에는 주차 원리를 도식으로 미리 학습한다. 유형별로 핸들을 언제 꺾는지 보여준다.
- **한계와 확장**
  - 카메라 영상은 서드파티 앱이 접근할 수 없다(문서 기준). 그래서 주차 칸을 인식해서 정밀하게 유도하는 기능은 넣지 않는다.
  - 향후 OEM이 카메라나 주차 공간 인식 API를 열어주면 정밀 유도로 확장한다(로드맵).
  - 정해진 출발 자세에서 속도와 조향각으로 궤적을 추정하는 방식도 검토했다. 다만 저속에서 오차가 커서 핵심 기능에서는 제외했다.

### ⑤ 주행 후 리포트와 다음 연습 과제 (정차 중)
- 리포트 항목: 깜빡이 사용률, 급제동 횟수와 위치, 과속 구간, 상황별 대응
- 다음 연습 코스 추천: "다음엔 회전교차로가 있는 ○○ 코스를 연습해봐요."
- 단계별 졸업 구조로 운영한다. 왕초보 → 초보 → 독립 운전.

## 4. "선생님 느낌" UX 원칙
- 짧고 다정한 말투로 교정하고 칭찬한다. 선생님 캐릭터(말투)는 선택할 수 있다.
- 주행 중에는 화면을 쓰지 않고 음성만 쓴다. 리포트와 도식은 정차 중에만 보여준다.
- STT로 대화한다. "지금 어떻게 해야 돼?"라고 물으면 현재 상황을 설명해준다.
- 음성 안내 앞에 150~200ms 무음을 넣는다.
- 오디오 포커스는 NAVIGATION 컨텍스트로 요청한다(`AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK`). 이렇게 하면 음악은 잠시 줄어든다.
- 같은 안내를 반복하지 않는다. 가이드라인에 따라 한 번에 핵심 한 문장만 말한다.

## 5. Gleo 음성 명령 (schema.json, 최대 3개)
| name | component | 파라미터 | 설명 (영어로 작성) |
|---|---|---|---|
| `START_DRIVING_LESSON` | activity | `level` (string, enum: BEGINNER / NOVICE / INDEPENDENT) | Starts a real-time driving coaching session for the selected skill level. |
| `START_PARKING_COACH` | activity | `parkingType` (string, enum: REVERSE / PARALLEL / FORWARD) | Starts step-by-step voice guidance for the selected parking maneuver. |
| `EXPLAIN_CURRENT_SITUATION` | service | (없음) | Explains the current road situation and what the driver should do next. |

※ 파라미터 타입은 string, number, boolean, array 중에서만 쓴다. integer는 허용되지 않는다. Callback은 7초 안에 보내야 한다.

## 6. 데이터 및 API 매핑
| 기능 | 데이터 | API | 확인 상태 |
|---|---|---|---|
| 조향각 | 실시간 각도 | Vehicle `SteeringWheel.registerSteeringWheelAngle` | ✅ API 존재 (권한 확인 필요) |
| 깜빡이 | 좌, 우, 비상 | Vehicle `TurnSignal.registerTurnSignalState` | ✅ `CAR_LIGHTS` |
| 브레이크 | 페달 값 | Vehicle `Brake.registerBrakePedalStatus` | ✅ `CAR_DRIVE` |

| 속도 | km/h | AAOS `PERF_VEHICLE_SPEED` | FAQ에 언급됨 |

| 와이퍼, 라이트 | 상태 | Vehicle `Wiper`, `Light` | 도메인 존재 |
| 상황 예고 | TBT, 주의 구간, 제한속도 | NaviHelper 이벤트 | ✅ 이벤트 존재 (필드 확인 필요) |
| 위치 | 좌표 | FusedLocation | `isSupported()` 확인 필요 |
| 음성 | 안내, 질문 | TextToSpeech / SpeechToText (ON_DEVICE 모드) | 앱 등록 불필요 |
| 카메라 | 후방 영상 | — | ❌ 서드파티 접근 불가 |

## 7. 주행 안전 설계
- `CarUxRestrictionsManager`로 주행 상태를 받아 화면 모드와 음성 모드를 자동으로 전환한다.
- 주행 중에는 키보드, 영상, 애니메이션, 긴 텍스트, 전체 화면 팝업을 쓰지 않는다.
- Back 키를 누르면 `moveTaskToBack(true)`로 앱을 숨긴다. `finish()`는 쓰지 않는다. 코칭 음성은 백그라운드에서도 계속 동작한다.
- 리소스 목표: 주행 중 CPU 5% 미만, RAM 400MB 이하.
- 이 앱은 연수를 보조하는 도구이고, 운전자의 판단과 법규 준수를 대체하지 않는다. 앱 안에서 이 점을 고지한다.

| 리스크 | 대응 |

| 에뮬레이터 GPS 경로 재생이 문서에 없음 | 상황 예고 데모는 이벤트를 모의 주입하는 방식으로 시연 |
| 잔소리 피로로 인한 이탈 | 개입 빈도를 단계별로 조절하고 칭찬 비율을 관리 |

## 9. 사업성
### 수익 모델
- **B2C 프리미엄 구독**: 상황별 심화 코스, 선생님 캐릭터
- **운전학원 B2B**: 학원 연수가 끝난 뒤 앱으로 이어서 학습. 학원에는 수강생 리포트 대시보드 제공
- **렌터카·카셰어링 B2B**: 초보 사용자 대상 코칭 모드로 사고율을 낮춤
- **보험사 제휴**: 센서로 검증된 운전 개선 데이터를 근거로 초보 보험료 할인

### 리텐션 설계
- 단계별 졸업 구조로 목표 의식을 만든다.
- 졸업 후에는 "안전운전 유지 모드"로 전환한다. 보험 할인과 연계해 계속 쓸 이유를 준다.

### 확인할 시장 지표 (기획서 작성 전에 조사)
- 연간 신규 운전면허 취득자 수
- 장롱면허 비율
- 초보운전자 사고 통계
- Pleos Connect 탑재 차량 출시 계획과 대수

## 11. 공모전 데모 계획 (에뮬레이터)
1. ~~**튜토리얼**~~: 제거(#35).
2. **주차 절차 코치**: 콘솔에서 기어를 D → R로 바꾸고 ACCEL·BRAKE로 움직였다 멈추며 조향각을 조작하면, 앱이 "끝까지 돌려요", "덜 돌렸어요", "가운데로 풀어요"라고 단계별로 음성 코칭한다(#37).
3. **상황 예고**: 회전교차로 이벤트를 넣으면 음성 안내가 나온다.
4. **실시간 피드백**: 깜빡이를 끈 상태에서 조향각을 바꾸면 경고가 나온다.
5. **주행 규제 전환**: `adb shell cmd hmg_car_service --service drivingstate driving_regulation on/off`로 규제를 바꾸면 UI가 음성 모드와 화면 모드로 전환된다.
6. **녹화**: `adb exec-out screenrecord`로 녹화해서 시연 영상(가산점)을 만든다.
