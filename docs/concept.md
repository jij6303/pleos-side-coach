# 초보운전탈출: 조수석 운전연수 선생님 앱

**한 줄 콘셉트**
차량 센서와 내비 경로를 실시간으로 읽고, **"지금 이 순간 무엇을 해야 하는지"** 음성으로 알려주는 초보운전자용 동승 연수 강사 앱.

**포지셔닝**
"주차를 대신 해주는 앱"이 아니라 **"도로 위 상황 판단과 조작을 가르쳐주는 앱"**.
길 안내는 차량 내비가 한다. 이 앱은 내비가 하지 않는 **조작 코칭과 규칙 설명**만 맡는다.

---

## 1. 문제와 타깃

### 타깃
- 신규 면허 취득자
- 장롱면허 복귀자
- 새 차나 처음 타는 차를 운전하는 사람 (렌터카, 카셰어링 포함)

### 문제
- 연수 강사는 비싸고 함께하는 시간도 몇 시간뿐이다. 혼자 운전을 시작하는 순간부터 막막해진다.
- 회전교차로, 합류, 비보호좌회전, 연속 회전처럼 **상황 판단이 필요한 구간**에서 실수가 많다.
- 깜빡이 누락, 급제동 같은 습관은 누가 옆에서 짚어주지 않으면 고쳐지지 않는다.
- 유튜브나 폰 앱은 운전 중에 쓸 수 없고, 내가 실제로 어떻게 조작하는지도 모른다.

## 2. 왜 폰이 아니라 차량 앱인가

| 구분 | 폰 앱 | 초보운전탈출 (차량 앱) |
|---|---|---|
| 조작 인식 | 불가 (GPS, 가속도 추정만 가능) | 조향각, 깜빡이, 브레이크, 기어, 속도를 **직접 판독** |
| 상황 예고 | 내비와 분리되어 있음 | 차량 내비 경로와 실시간 연동 |
| 주행 중 사용 | 화면 조작이 위험함 | 주행 중에는 음성만, 정차 중에만 화면. 주행 규제(CarUxRestrictions)에 맞춰 자동 전환 |

## 3. 핵심 기능

### ① 실시간 조작 코칭 (주행 중, 음성)
차량 신호로 실제 조작을 확인하고 그 즉시 짧게 교정하거나 칭찬한다.

| 코칭 | 언제 말하나 |
|---|---|
| 깜빡이 누락 | 차선을 바꿨는데 3초 전부터 깜빡이가 꺼져 있었을 때 |
| 급제동 | 감속이 크고 브레이크를 밟았을 때 (저속·후진 제외) |
| 회전 중 과속 | 핸들을 크게 꺾은 채 30km/h 이상일 때 |
| 움직이는 중 기어 변경 | 차가 움직이는 동안 D↔R, D/R→P로 바꿨을 때 |
| 깜빡이 끄기 잊음 | 차선 변경이 끝났는데 깜빡이가 계속 켜져 있을 때 |
| 칭찬 | 깜빡이를 켜고 차선을 바꾼 횟수가 쌓였을 때 |

- 여러 코칭이 한꺼번에 생기면 우선순위와 간격을 정해 한 번에 하나만 말한다.

### ② 상황 예고 (주행 중, 음성)
내비 경로(TBT)를 받아서 상황이 **오기 전에** 무엇을 할지 말해준다. 회전 안내 자체는 내비가 하므로 반복하지 않는다.

| 상황 | 음성 예시 |
|---|---|
| 회전 전 차로 준비 (500~200m 전) | "좌회전 준비해요. 깜빡이 먼저 켜고 왼쪽 끝 차로로 미리 옮겨요." |
| 연속 회전 (앞 회전 직전) | "이번에 돌 때 오른쪽 차로로 들어가요. 바로 우회전이 이어져요." |
| 내 차로 기준 안내 | "지금 2차로예요. 좌회전하려면 깜빡이 켜고 1차로로 옮겨요." |
| 회전교차로 | "돌고 있는 차가 우선이니 왼쪽을 보고 천천히 들어가요"처럼 통행 규칙을 300~150m 전에 설명 |

- 운전자가 Gleo나 화면 버튼으로 지금 차로를 알려주면, 앱이 차선 변경을 따라가며 차로를 기억하고 안내를 단정형으로 바꾼다.
- 내비 경로가 없을 때는 시연용 가상 경로(회전교차로, 어린이보호구역, 비보호좌회전, 합류)로 규칙 안내를 들려준다.

### ③ 주차 절차 코치 (후진, 음성)
카메라 없이 실제 연수 강사 방식대로 가르친다. 판단하는 눈은 운전자이고, 앱은 다음을 맡는다.

1. **절차 안내**: 후진 주차(5단계), 평행 주차(9단계)를 기준점과 함께 음성으로 안내한다.
   - 예: "뒷바퀴가 주차선 끝을 지나는 순간 핸들을 끝까지 꺾으세요."
2. **조작 확인**: 조향각을 읽어서 "아직 끝까지 안 꺾었어요", "가운데로 풀어요"처럼 바로잡는다.
3. **다음 단계로**: 운전자가 기준점에서 차를 세우면 "움직인 뒤 정지"를 감지해 다음 단계로 넘어간다.

- 주행하다가 기어를 R로 바꾸면 자동으로 시작하고, P로 바꾸면 끝난다. 주차 유형은 정차 화면에서 고른다.
- R 기어에서는 시스템 후방카메라 화면이 앱을 덮으므로, 화면 입력 없이 음성과 차량 신호만으로 진행한다.

### ④ 주행 후 성적표 (정차 중)
- 주행이 끝나면(P) 점수, 등급, 항목별 기록(깜빡이 사용률, 급제동, 회전 과속 등)을 보여준다.
- 가장 고쳐야 할 습관 하나를 **다음 연습 과제**로 정해 음성으로 요약한다.

### ⑤ 차량 기능 도움말 (정차 중)
김 서림 제거(앞·뒤), 내기/외기, 에어컨, 가속 모드, 회생제동, 가속 페달 모드, 차일드락 사용법을 버튼 그림과 음성으로 설명한다. Gleo로 물어봐도 음성으로 답한다.

## 4. "선생님 느낌" UX 원칙
- 짧고 다정한 말투로 교정하고 칭찬한다. 한 번에 핵심 한 문장만 말한다.
- 주행 화면에는 강사 캐릭터 얼굴과 말풍선 하나만 보여준다.
- 자주 나오는 문구는 직접 녹음한 사람 목소리로 재생한다.
- 말할 때는 음악 소리를 잠시 줄이고(오디오 포커스 NAVIGATION, `GAIN_TRANSIENT_MAY_DUCK`), 다른 앱이 포커스를 가져가면 바로 멈춘다.
- 같은 안내를 반복하지 않는다.

## 5. Gleo 음성 명령

| name | 파라미터 | 하는 일 |
|---|---|---|
| `START_DRIVING_COACH` | 없음 | 코칭을 시작한다 |
| `SET_CURRENT_LANE` | `laneNumber` (1~4, 1이 가장 왼쪽) | 지금 차로를 기억하고 음성으로 확인한다 |
| `ASK_CAR_TIP` | `topic` | 차량 기능 사용법을 음성으로 답한다 |

## 6. 사용하는 차량 데이터

| 데이터 | API | 쓰는 곳 |
|---|---|---|
| 조향각 | Pleos Vehicle `SteeringWheel` | 차선 변경 인식, 회전 과속, 주차 핸들 확인 |
| 깜빡이 | Pleos Vehicle `TurnSignal` | 깜빡이 누락·끄기 잊음 |
| 브레이크 | Pleos Vehicle `Brake` | 급제동 |
| 기어 | AAOS `GEAR_SELECTION` | 주행 시작·종료, 주차 코치, 기어 변경 경고, 화면 모드 |
| 차속 | AAOS `PERF_VEHICLE_SPEED` | 급제동, 회전 과속, 남은 거리 계산, 주차 기준점 |
| 주행 규제 | AAOS `CarUxRestrictionsManager` | 주행/정차 화면 전환 |
| 내비 경로 | Pleos `NaviHelper` TBT | 상황 예고 |
| 음성 | `MediaPlayer`(녹음 클립), Android `TextToSpeech` | 모든 안내 |

## 7. 주행 안전 설계
- 주행 규제 중에는 큰 코칭 카드 하나만 보여주고 키보드, 영상, 애니메이션, 전체 화면 팝업을 쓰지 않는다.
- 규제 상태를 알 수 없으면 가장 엄격한 "주행 중"으로 취급한다.
- Back 키를 누르면 `moveTaskToBack(true)`로 앱을 숨긴다. 코칭은 Foreground Service에서 계속 동작한다.
- 앱이 강제로 다시 시작돼도 진행 중인 주행 세션을 이어간다.
- 이 앱은 연수를 보조하는 도구이고, 운전자의 판단과 법규 준수를 대체하지 않는다.

## 8. 기술적 한계

| 한계 | 대응 |
|---|---|
| 서드파티 앱은 카메라 영상을 쓸 수 없다 | 주차는 기준점 교육 + 조향각 확인 방식. 정밀 유도는 로드맵 |
| 내비 SDK에 차로 정보가 없다 | 회전 종류 기반 차로 안내 + 운전자가 알려준 차로 추적 |
| 비상등 상태를 읽을 권한이 없다 (signature 권한) | 깜빡이 누락 판정은 비상등 여부 없이 동작 |
| 에뮬레이터에 표준 TTS 엔진이 없다 | 정해진 문구는 녹음 클립으로 재생 |
| 차량 권한은 App Market 승인이 필요하다 | 조회 전용 최소 권한만 선언 |

## 9. 사업성

### 수익 모델
- **B2C 프리미엄 구독**: 상황별 심화 코스, 선생님 캐릭터 선택
- **운전학원 B2B**: 학원 연수 뒤 앱으로 이어서 학습, 학원에는 수강생 리포트 대시보드 제공
- **렌터카·카셰어링 B2B**: 초보 사용자 대상 코칭 모드로 사고율을 낮춤
- **보험사 제휴**: 센서로 검증된 운전 개선 데이터를 근거로 초보 보험료 할인

### 리텐션 설계
- 성적표의 다음 연습 과제로 매 주행마다 목표를 준다.
- 익숙해진 뒤에는 "안전운전 유지 모드"로 전환하고 보험 할인과 연계한다.

## 10. 공모전 예시와의 차별화
공모전 개발 가이드의 예시인 "안전운전 점수 앱"과 비교하면:

| | 안전운전 점수 앱 | 초보운전탈출 |
|---|---|---|
| 시점 | 주행 후 사후 분석 | **주행 중 실시간 동승 코칭** |
| 내용 | 점수 매기기 | **지금 무엇을 해야 하는지 가르쳐주기** |
| 상황 인식 | 운전 습관만 봄 | 내비 경로로 **다가올 상황을 예고** |
| 학습 | 없음 | 주차 절차, 차량 기능 도움말, 다음 연습 과제 |

## 11. 로드맵
